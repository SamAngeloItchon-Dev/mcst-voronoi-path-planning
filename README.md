# mcst-voronoi-path-planning

# Voronoi-Based Path Planning with Adaptive Multi-Criteria Cost Function

weight_sweep.py       - tests the 9 weight combinations (50 trials each, seeds 1-50)
final_90_trials.py    - final test: 9 conditions x 10 trials (seeds 1001-1010)
final_results_tables.xlsx        - results of the 90 final trials
weight_screening_results.xlsx    - results of the weight screening

Requirements: Python 3, numpy, scipy
Run: python final_90_trials.py
